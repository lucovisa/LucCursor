# LucCursor

Create custom Windows cursors right in your browser. Draw pixel-art cursors and export them as an installable pack.

## Features

-  Pixel-art cursor editor
-  Support for all Windows cursor types (Normal, Pointer, Text, Wait, Help, etc.)
-  Export as ZIP with installer
-  No registration required, works offline

## How to Use

1. Open the [LucCursor website](https://lucovisa.github.io/luccursor/)
2. Select a cursor type from the list (Normal Select, Help Select, Working in Background, Busy, etc.)
3. Draw your cursor on the pixel grid
4. Repeat for each cursor type you want to customize
5. Click **Download ZIP** when finished
6. Extract the ZIP file
7. Double-click `install.inf`
8. Confirm the installation when Windows asks
9. Go to **Settings → Bluetooth & devices → Mouse → Additional mouse settings → Pointers**
10. Select the scheme you just installed and click **Apply**

## Installation Troubleshooting

**"Windows protected your PC" warning:**
- Click "More info" → "Run anyway"

**Cursors not showing in list:**
- Make sure you selected the correct scheme name in Mouse Properties

**Want to restore default cursors:**
- Go to Mouse Properties → Pointers → Select "Windows Default (system scheme)" → Apply
